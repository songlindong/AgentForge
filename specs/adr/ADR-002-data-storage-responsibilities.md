# ADR-002：数据存储职责

状态：Proposed  
日期：2026-07-26

## 背景

系统同时需要事务数据、短期状态、异步事件、原始文件、BM25、向量和审计，不能让一个数据库承担所有职责。

## 决策

- MySQL 8.0+：租户、用户、权限、Agent/Skill、Run/Task、文档元数据、配置和审计索引。
- Redis：短期会话、幂等、限流、配额、热点缓存和临时状态。
- Kafka：用户消息、文档处理、Agent 事件、审计和评测事件。
- MinIO：原文件、缩略图、OCR/版面/表格结果和报告。
- OpenSearch：BM25 全文检索。
- Milvus：文本、表格和图片向量检索。

## 不采用

- 不让 MySQL 承担向量检索。
- 不让 Redis 成为唯一事实来源。
- 不把原始敏感文件写入普通日志。
- 不让应用绕过元数据直接使用未授权对象。

## 后果

必须维护数据版本、同步状态、重建脚本、备份策略和跨存储一致性检查。

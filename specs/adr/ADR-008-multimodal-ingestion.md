# ADR-008：多模态文档入库流水线

状态：Accepted
日期：2026-07-26

## 背景

金融产品、政策和合同可能是原生 PDF、扫描 PDF、图片或带复杂表格的文档。直接把文件交给模型不能保证安全、结构和引用准确。

## 决策

- P0 支持 PDF、扫描 PDF、PNG/JPEG。
- 文件先做 MIME/魔数、大小、页数、解压比例、恶意内容和 EXIF 检查。
- 不可信解析在默认禁网的沙箱执行。
- 保存原文件、页码、区域坐标、OCR 文本、版面、表格、提取器版本和租户元数据。
- 解析结果通过 Kafka 异步进入切片、Embedding、OpenSearch 和 Milvus。
- 引用可以回到原文件页码或区域。
- P1 支持 APP/H5 图片问答，P2 预留 ASR/TTS，不做视频理解和图片生成。

## 后果

需要多模态人工标注集、OCR CER、表格 F1、区域定位、引用正确率和解析安全测试。多模态内容会增加存储、GPU/CPU 和队列容量，需要在性能环境单独测量。
